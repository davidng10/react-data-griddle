## DataGridHandle

Pass a ref to reach the grid's commands:

```tsx
const gridRef = useRef<DataGridHandle>(null);

<DataGrid ref={gridRef} {...props} />;

gridRef.current?.focusCell({ rowId: 42, columnId: "name" });
```
